The machine from the video — a horizontal flow-wrap (“pillow pack”) machine

This machine wraps each candy from a roll of film, then heat-seals and cuts it into an individual “pillow” pack. The trade name is a horizontal flow-wrap machine (also called a pillow packing machine). Below are real suppliers with prices and one-tap contacts.
